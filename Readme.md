# Instructions

## Run Using Streamlit

`app.py` serves as the frontend file. Launch it with Streamlit using the following command:

```bash
streamlit run app.py
```
## Run Using Terminal
To run the application directly from the terminal without the web interface:

1. Open `pipeline.py`.
2. Locate the `main` function.
3. Uncomment the code within `main`.
4. Delete `None` Statment.
5. Save the file and execute:

```bash
python pipeline.py
```
